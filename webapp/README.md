# Веб-застосунок «Прогноз схвалення займу» (Django)

## Запуск на Mac (одна команда)

1. Розпакуйте архів у НОВУ папку (не поверх старої).
2. Відкрийте Terminal, введіть `cd ` (з пробілом), перетягніть папку `loan_site` з Finder у термінал, натисніть Enter.
3. Введіть: `bash run.sh`
4. Дочекайтеся рядка «Starting development server» і відкрийте http://127.0.0.1:8000/
5. Зупинити сайт: Ctrl + C.

Наступного разу достатньо кроків 2–3: скрипт сам пропустить те, що вже зроблено.

Скрипт створює окреме середовище `.venv`, тож усі бібліотеки й навчання моделі працюють в одному й тому ж Python.

## Що де лежить (для презентації)

| Файл | Технологія | Що робить |
|---|---|---|
| train_model.py | pandas, scikit-learn, joblib | навчає модель (поділ 80/20, Pipeline, GridSearchCV), зберігає її і перевіряє |
| predictor/ml.py | joblib, pandas | завантажує модель і дає прогноз |
| predictor/models.py | Django ORM | таблиця заявок у базі даних (SQLite) |
| predictor/forms.py | Django Forms | форма і перевірка введених даних |
| predictor/views.py | Django Views | логіка сторінок «Прогноз» та «Історія» |
| predictor/urls.py | Django URLs | адреси сторінок |
| predictor/templates/ | Django Templates, HTML, CSS | вигляд сторінок: «Перевірити займ», «Історія перевірок», «Як це працює» |
| run.sh | bash | автоматичний запуск |

## Як це працює

Користувач заповнює форму. Django перевіряє дані (forms.py), передає їх у модель (ml.py), отримує «схвалено/відхилено» та імовірність, зберігає заявку в базу (models.py) і показує результат. На сторінці «Історія перевірок» видно всі збережені прогнози та коротку статистику, а на сторінці «Як це працює» описано сервіс, технології й обмеження. Під результатом є блок «Що саме отримала модель», де видно, які дані пішли в модель.
